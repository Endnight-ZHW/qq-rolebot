# 素材管理

默认素材库为空，没有预置角色图、表情、背景或可还原原始图案的生成脚本。无需素材也可通过 Python 或网页代码制作图表和原创几何场景。

在后台「任务中心 → 美术素材」上传 PNG/JPEG/WebP/GIF 或安全 SVG，可以编辑名称、用途、绑定角色、启停和删除。人物素材必须绑定角色，其他角色不能读取。SVG 在隔离环境生成预览，源码仅作为下载文件，不在后台同源执行。

素材文件保存在运行数据目录的 `creation-assets`；元数据位于数据库。两者均不提交 Git。开始制作和发送前再次核对素材版本、启用状态与权限。

普通聊天不注入素材目录。制作中仅在有明确用途时调用 `art_search` 和 `art_read`；用户询问素材可用 `creation_create(operation=list_assets)`，这不代表入队。`character=none` 禁止人物装饰；`current` 使用当前角色的已授权外观参考；`auto` 根据当前角色名称、别名和原请求判断。缺少必要参考时给出明确提示，不用别人的素材替代。

本地回归临时生成纯几何图形验证透明度、版本、权限、删除和上传。测试素材不会进入发行文件。
