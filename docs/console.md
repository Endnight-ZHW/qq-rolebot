# 机器人工作台

后台采用紧凑的浅色工作台。会话管理使用列表，权限使用可搜索工具表和侧栏，参数按用途分类；桌面与手机共用配置定义。

## 导航

| 入口 | 内容 |
| --- | --- |
| 总览 | 全局连接状态、调用指标、趋势、异常、群运行概况和近期任务 |
| 会话管理 | 群与已有私聊列表；概况、聊天设置、成员与学习、记忆与上下文、表情和权限中心 |
| 角色库 | 角色编辑、人物关系、导入导出、复制和版本恢复 |
| 任务中心 | 跨群筛选、任务创建与编辑、暂停恢复取消、执行记录 |
| 观测中心 | 请求追踪、模型调用、日志、费用与 token 统计、效果检查 |
| 模型与服务 | 模型供应商、用途路由、全局模板及单群覆盖 |
| 系统设置 | 基础信息、上下文与记忆、图片预算、数据保留、费用、安全与备份 |

群工作区的会话范围由地址中的 `scope` 决定。全局页面通过各自的范围筛选查看所有会话或指定会话，系统诊断包含在“全部会话与系统”中。已有私聊会话明确标注类型，隐藏 QQ 群专属权限。

角色、记忆、表情、任务执行记录、请求追踪和模型调用可通过地址中的编号再次打开。路由使用 Vue Router 的 history 模式，Vite 开发服务和现有 Caddy 的 `try_files` 均支持直接打开页面地址。

## 编辑与异常处理

- 表单修改保留在当前页面的草稿中；离开页面、切换会话或切换编辑对象前，可选择保存、放弃或继续编辑。
- 保存失败保留草稿。权限中心、聊天和全局配置校验版本；冲突显示服务器变更，不自动覆盖。配置表单每个编辑区域只有一个保存条，可查看变更（密钥隐藏）、保存或放弃。权限中心内部切换视图保留同一草稿。
- 概况、聊天设置和权限中心提供即时暂停、恢复及管理工具控制；局部更新带版本号，仅提交操作本身，不附带页面中的其他草稿。
- 群概况的运行操作区提供紧凑的群聊／私聊总开关，区分当前生效状态和待保存修改。关键设置使用带文字状态的滑动开关，点击区域至少 44px；暂停与紧急停用分别使用黄色、红色。
- 状态显示文字和颜色，结果未知、中断、未发送不当作成功。
- 桌面详情使用侧边抽屉；手机使用全屏详情和抽屉导航，支持 Escape 关闭和 Tab 焦点循环。
- 全局健康状态每 15 秒刷新，统计每 30 秒刷新，日志每 15 秒刷新。页面不可见时暂停轮询，恢复可见后刷新。轮询只更新运行数据，不覆盖正在编辑的表单。
- 登录失效后返回登录页面，重新登录后回到原页面；密码更改按原规则使所有后台登录失效。
- 登录页仅输入管理员密码；可选“记住登录 30 天”，默认有效期 12 小时。会话存放在 HttpOnly Cookie 中，不与其他子域名共享，退出立即撤销当前会话。

## 指标口径

`GET /api/v1/dashboard` 为管理员只读接口，接受可选 `scope`、`start`、`end`（Unix 秒）。默认最近 24 小时，最大查询跨度 31 天。时间区间包含起点、不包含终点。

返回 `generated_at`、`range`、`health`、`metrics`、`series`、`purposes`、`groups`、`alerts`、`tasks`。`health` 始终表示全局连接状态；其他统计按选定会话过滤。待执行任务表示当前待办，不限定在历史图表的时间段内。

- `metrics.calls` 为当前留存的实际接口尝试数，包括重试，数据来自 `model_calls` 元数据；统计不读取或解压请求正文。
- 成功率分母为 `success`、`http_error`、`network_error`、`invalid_response`、`error` 的总数。运行中、未发送、取消和中断放在 `excluded` 中单列。
- P95 使用同一分母集合内有效的非负耗时，采用排序后 `ceil(N × 0.95)` 的样本；无样本返回 `null`。
- 小于或等于 48 小时的查询按小时分桶，更长时间按北京时间自然日分桶。界面提供 24 小时、7 天、30 天快捷选择。
- `range.coverage_start` 是当前保留期与最早留存记录共同确定的保守起点。更早的时间桶返回 `null`，跨起点的时间桶标记 `partial`。保留期内曾经清理的记录也无法补回。
- 费用和 token 使用独立的 `usage` 账本。输入 token 已包含缓存 token，堆叠图使用“非缓存输入 + 缓存输入 + 输出”。不同币种不相加、不换算。
- 图表提供文字摘要及数据表，无数据时显示空状态，不绘制虚构的占比。

原 `/usage` 新增可选 `scope/start/end`；原 `/traces` 新增 `start/end/status/kind`；原 `/model-calls` 新增 `start/end/model`，`status=failure` 聚合明确失败状态；原 `/audit` 新增 `start/end/status`。已有参数、数组返回结构及不传新参数的行为保持兼容。查询时间索引在数据库打开时幂等创建。

## 本地验证

所有写操作回归仅运行于临时数据库，`tests/ui_server.py` 使用 `start_engine=False`，并在同一文件中提供多群、私聊、记忆、任务、调用和多币种用量的合成数据，不启动 QQ 或模型工作任务。日常冒烟保留完整页面、交互和移动端检查，仅失败时截图；需要全部验收截图时运行 `npm --prefix frontend run test:ui -- --screenshots`，避免每轮重复生成大量文件。

```powershell
# 终端一
$env:PYTHONPATH='backend'
.venv\Scripts\python tests/ui_server.py
# 终端二
npm --prefix frontend run dev
# 终端三
npm --prefix frontend run test:ui
```

浏览器回归覆盖主要编辑流程、失败保存、并发冲突、跨权限视图的原子保存、即时控制与草稿隔离、详情地址、权限诊断、登录过期，以及 1440 / 1024 / 390px 下的全部页面。截图输出至 `artifacts/browser/`。

```powershell
npm --prefix frontend run build
.venv\Scripts\python -m pytest -q
```

`test:public` 保持只读巡检：登录、访问页面、切换导航和截图；不执行配置修改、任务操作、模型测试或提示词发布。

发布仍使用项目已有的候选镜像、隔离验证和部署流程；运行参数由后台配置；配置上限放宽后，管理员保存的新值作用于后续请求。


## 权限中心

`/groups/:scope/access` 是统一入口；`view` 可为 `tools`、`members`、`roles`、`rules`、`diagnostics`。`tool` 可定位工具侧栏，`user` 可定位成员。旧 `/tools` 和 `/permissions` 地址分别跳转到工具与成员视图，并保留其余查询参数。

工具授权明确分为“沿用账号授权”与“按身份配置”。分类权限、账号例外和权限组沿用原判定顺序；升级不会自动切换模式。快捷配置只进入草稿。成员恢复默认继承、创建或删除权限组同样在保存时提交。

诊断使用已保存的配置，列出会话、管理停用、互动扩展、工具开关、服务配置、用户请求和身份授权检查。身份未知不能视为普通成员已通过核实。保护目标、实际禁言时长、实时额度、冷却和 QQ 回执仍需在执行时检查，页面不承诺未来请求一定成功。

## 参数与运行额度

数值定义集中于 `backend/rolebot/config_schema.py`，包含单位、默认值、建议上限、硬边界、作用范围及依赖。前端 `NumberField` 读取定义，秒数可切换为分钟、小时输入；超出建议范围显示提示而不阻止保存。整数有 32 位正整数工程边界；原有零值和空值语义不变。

跟聊窗口、发言及工具额度、分段、上下文消息数量、模型容量、保留期、表情收藏数、程序点赞数量均可超过旧业务上限。模型输出仍不能超过配置的模型容量，实际请求预算取全局预算与路由剩余容量的较小值。模型能力是管理员声明，不代表上游服务保证支持。

图片数量硬上限为单次 128 张，请求体为 128 MiB；视觉输入预算与模型容量同时生效。单文件 8 MiB、解码像素与动画帧数边界保留。概率为 0–100%，群禁言兼容上限为 2592000 秒。

会话的“聊天设置 → 运行额度”新增：

| 配置字段 | 默认 | 行为 |
| --- | --- | --- |
| `send_per_minute` | 20 | 每分钟实际发送尝试，包括结果未知的尝试 |
| `send_wait_seconds` | 65 | 请求回复等待发送额度的最长秒数；0 表示不等待 |
| `reply_timeout_seconds` | 120 | 普通回复与格式补救的有效时限 |
| `forward_reply_timeout_seconds` | 300 | 已读取合并转发多图时的回复有效时限 |
| `tool_max_rounds` | 4 | 单轮模型交互次数，2–32，最后一次不提供工具 |
| `tool_max_calls` | 6 | 单轮最多执行工具次数，1–256，聊天与定时任务共用 |

分段算法支持超过 3 段，按真实标点和发送额度限制段数。代码块、列表等结构保持完整。点赞默认单次和每日各 10，支持管理员提高程序额度；跨群计数、原子预留、去重、明确拒绝与未知结果处理不变，不会自动补赞。

## 配置接口兼容

- `GET /api/v1/config-schema` 返回 `{version, fields}`；字段 ID 为 `作用范围.字段名`。
- `GET/PUT /api/v1/groups/{scope}/access` 使用 `{group_revision, interaction_enabled, tools, permissions}`；`permissions.revision` 是第二个版本号。两套版本均匹配才在一个事务中写入群与账号权限及审计；任一失败全部回滚，冲突返回 409。
- `PATCH /api/v1/groups/{scope}` 接受 `expected_revision` 和待修改字段，只修改显式提供的内容；合并后再次检查关联参数。
- `PUT /api/v1/settings?expected_revision=N` 支持版本校验；`GET /settings` 返回 `revision`。新前端一次提交全局配置与模型调用保留期限，更新记录过期时间后再执行清理。
- 旧群 PUT、工具权限、账号权限、互动设置和模型日志保留接口继续可用。旧工具和新权限入口共用策略校验与保存规则；旧客户端省略新参数时保留已保存的值。

回退代码沿用已有发布流程。若需要回退到只接受旧上限的版本，应先用当前界面把超出旧范围的配置调整为旧版本可接受值；回退不恢复或删除聊天数据。
